# ASIR LAB

Laboratorio personal de administración de sistemas y redes
como preparación para el ciclo de Administración de Sistemas
Informáticos en Red (ASIR).

## Objetivos

- Administrar sistemas Linux y Windows Server.
- Profundizar en redes y servicios de red.
- Aprender administración remota mediante SSH.
- Trabajar con Active Directory.
- Administrar servidores web y bases de datos.
- Aprender Docker y virtualización.
- Automatizar tareas mediante Bash, PowerShell y Ansible.
- Implementar monitorización y medidas de seguridad.
- Documentar procedimientos e incidencias.

## Infraestructura

El laboratorio estará compuesto por máquinas virtuales y
servicios aislados para practicar administración de sistemas.
